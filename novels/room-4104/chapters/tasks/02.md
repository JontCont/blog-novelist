# 第二章任務 — 迷失

- Status: proposed
- Viewpoint: 煒
- Time and location: 第一章隔天早上至當日晚間；高雄德安大樓的面試地點、地下一樓警衛室、十層大樓的正常公共樓層、電梯，以及煒回到的宿舍。
- Outline reference: outline/outline.md 的「第二章〈迷失〉」。
- Chapter goal: 讓煒完成夜班警衛職缺面試並正式開始第一天工作，由即將離職的前輩帶他熟悉十層大樓、警衛室、電梯與正常樓層格局；在探索途中短暫失去前輩的帶路，讓「迷失」先發生在大樓，再讓工作中的異常跟回宿舍。
- Opposition: 煒對公司與高薪職缺仍存疑、陌生工作規則、前輩刻意避談四樓與 4104、前輩突然消失造成的方向中斷、正常格局與交接資料的缺口，以及回宿舍後物件位置改變造成的記憶不確定。
- Emotional movement: 煒從擔心面試又是騙局，轉為因錄取與前輩帶看而短暫相信自己抓住工作；前輩消失後他失去方向，回到宿舍又開始懷疑自己的記憶與工作現場是否已經跟著他一起回來。

## Required Beats

1. 以第三人稱限知、現在式承接第一章，讓煒隔天早上前往德安大樓面試；面試確認職缺是夜班警衛，薪資比一般保全每月多一萬元，且不要求任何保證金或費用。
2. 讓煒正式進入十層、五十年歷史的德安大樓，先認識地下一樓警衛室；交接內容包含值班、門禁、巡查與異常紀錄，但不讓管理方解釋 4104 的真相。
3. 讓即將離職的前輩警衛先帶煒搭電梯到十樓，再由頂樓一層一層往下介紹警衛室以外的正常公共格局；到四樓時讓煒看見住戶與正常生活痕跡，前輩只刻意避開 4104，並說出「不要靠近 4104 房間，也不要靠近電梯」的工作禁令。回程時前輩先走向樓梯，煒問「不是搭電梯嗎？」；前輩往下行並逐漸消失，煒在四樓看到模糊、像是三樓的紅光後不敢靠近，直接衝回地下一樓警衛室。電梯人影指向身後，煒回頭看見樓梯口門牌寫著「四樓」，再轉回來時有一道黑影從電梯門內衝出，作為本章恐懼最高點。
4. 讓前輩在十樓樓層圖前要求煒把每層地圖拍下來，表面理由是值班防止迷路，並留下「如果有人找不到出口，照片比記憶可靠」的提示；再讓煒在交接資料或值班紀錄中看見 4104 作為公宅雛形的模糊註記，四樓欄位直接寫著「不要靠近 4104」，旁邊的每月整理欄位卻找不到房客、維修或公開事故說明。對 4104 的空白先以管理方的舊規定解釋，不提前揭露十名死者、十誡或惡魔。
5. 讓前輩在下行途中短暫消失；煒直接衝回地下一樓警衛室，關上門等待，卻找不到前輩，也無法解釋自己如何從四樓回到警衛室。數分鐘後前輩從警衛室外出現，只說自己去處理事情，拒絕解釋細節。
6. 讓前輩完成交接後離開或準備離職，煒獨自完成第一天的基本工作；他記住正常電梯提示音、樓層顯示與各樓層格局，建立第三章可比對的現實參照。
7. 讓煒回到宿舍後翻閱記錄十樓至地下樓層的筆記本，也查看手機裡剛拍下的樓層地圖；再發現工作證、鑰匙或筆記本位置與離開時不同。他反覆回想自己是否放錯，卻找不到被移動的證據，將異常維持在心理與超自然之間。
8. 章末讓煒在宿舍聽見電梯抵達的提示音，拿手機收音；錄音只留下被截斷的管理員聲音或不完整人聲，沒有明確說出 4104、惡魔或任何完整指令。

## Continuity Constraints

- 煒在本章為 active，保持第三人稱限知現在式；第一章的詐騙創傷與對高薪職缺的懷疑仍存在，但不得讓他突然恢復自信或變成全知調查者。
- 德安大樓共有十層，地下一樓是警衛室；煒本章先搭電梯到十樓，再由頂樓往下走過正常公共樓層，四樓可以停留並看見住戶，但不可進入 4104 或其異常長走廊。
- 前輩警衛是「即將離職」的既定角色，本章描寫其離職前的帶看與交接；不得新增姓名、家庭、受害經歷或讓他成為新受害者。寫作 continuity check 時需使用已批准的 `--allow-return senior-guard`，因 registry 的 departed 狀態代表他在本章後離開。
- 前輩消失只能持續數分鐘，發生在四樓下行至警衛室的過程，且不確認是超自然、迷路或管理方安排；不得把他寫成死亡、失蹤或 4104 祭品。
- 電梯抵達聲、模糊而像三樓的紅光、緩慢開門、模糊人影指向煒身後、樓梯口的「四樓」標示與從電梯門內衝出的黑影，在前輩消失後形成恐怖最高點；煒不可在現場停留太久，不得確認任何人影身分，也不得新增第二名前輩角色。章末仍可保留宿舍提示音與截斷收音，但不可再重複同一個電梯開門橋段。
- 4104 只能以禁令、空白欄位、避談或遠距標示出現；不得揭露十名死者、十誡順序、管理員殘留意識或惡魔身分。
- 每月整理是已確認設定，本章只植入固定紀錄與缺失資料；S-01、S-02、S-09 可以建立或確認，但不可提前回收其後段真相。
- 電梯本章保持正常外觀與可辨識運作；四樓回程前輩改從樓梯先行下去，主要怪事是煒仍在四樓卻從遠處看見疑似三樓的模糊紅光，並選擇沿樓梯下行；不可出現長走廊或四樓高溫。
- 不描寫露骨血腥、性內容或性暴力；本章不讓任何角色死亡、失蹤或被取代。

## Relevant Setups

- S-01: 4104 是公宅雛形，出租與入住紀錄不完整且每月整理，透過交接資料中的固定整理欄位植入。
- S-02: 煒從地下一樓警衛室進入電梯、再巡查樓層的工作路線在本章建立。
- S-07: 第一章已確認煒的自我否定；本章讓他在錄取後短暫相信自己能重新開始。
- S-09: 前輩帶煒看過正常樓層格局，本章完成植入並確認為第三章辨認異常的參照。
- S-10: 前輩帶看途中短暫消失，本章建立其「失去帶路者」的恐怖環節，但不回收原因。
- S-15: 前輩明確警告「不要靠近 4104 房間，也不要靠近電梯」，後續讓煒在電梯與 4104 事件中回想這句話。
- S-11: 四樓正常住戶與 4104 封鎖並存，本章只建立外篇可用的生活背景，不回收住戶真相。
- S-12: 前輩要求煒拍下各層樓地圖，並暗示照片能幫助受困者找到出口；本章只建立提示，不揭露未來要拯救的對象。
- S-14: 煒仍在四樓卻從遠處看見電梯內疑似三樓的模糊紅光，電梯人影指向他身後，樓梯口門牌寫著「四樓」，隨後有黑影從電梯門內衝出。

## Exit State

- New situation: 煒完成第一天入職與基本交接，回到宿舍；他已知道正常樓層與電梯的樣子，卻在宿舍聽見不應出現的電梯提示音，也無法解釋前輩短暫消失。
- Character state changes: 煒從面試的不信任轉為暫時接受工作，又因前輩消失、物件位置改變與截斷收音而重新懷疑自己的記憶與工作現場。
- Knowledge revealed or concealed: 煒知道德安大樓共有十層、警衛室與正常樓層格局，也知道四樓有正常住戶；他只知道 4104 是公宅雛形、資料不完整、被禁止靠近且每月整理，不知道它是否曾出租、十起死亡、祭品順序、惡魔或管理員殘留意識。
- Next pressure: 第二夜值勤時，煒會把收音設備帶到警衛室，開始主動記錄電梯雜訊。

## Retrieval Query

第一章摘要與煒的目前狀態；德安大樓十層、五十年歷史、地下一樓警衛室與樓梯；夜班警衛面試與每月高於一般保全一萬元且不需保證金；離職前輩警衛 senior-guard 的正常樓層帶看、四樓正常住戶生活、四樓按下三樓後改走樓梯與空電梯慢慢開門、各層樓地圖拍照與「照片比記憶可靠」提示、正常走廊中短暫消失、離職前交接與 departed 狀態例外；電梯正常提示音、樓層顯示與巡查路線；4104 公宅雛形、出租與入住紀錄不明、禁止靠近、每月整理；宿舍物件位置改變與截斷人聲；S-01、S-02、S-07、S-09、S-10、S-11、S-12 的建立邊界；第三人稱限知現在式與 15+ 內容界線。
